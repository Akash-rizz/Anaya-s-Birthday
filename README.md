ANAYA · XVII — A Little Universe of Her Own

A cinematic, single-file birthday website for Anaya's 17th birthday (28 October).
Royal Noir × Celestial Luxury aesthetic. Zero dependencies, no backend, works offline.

Features

- Cinematic intro sequence (with Skip + auto-dismiss so it never traps visitors)
- Rose-gold editorial hero with live canvas starfield + orbiting particle rings
- Live countdown to 28 October (switches to "It's her day" after midnight)
- Seamless luxury marquee divider
- Sealed-envelope letter with cinematic open interaction + Read All
- Five interactive wishes with 3D tilt + light-tracking hover
- Hidden constellation interlude — tap 5 stars to draw her initial
- Secret celestial star with champagne-light reveal + dedication
- Final frame with particle celebration + full replay
- Optional generative ambient music (Web Audio — no audio file, off by default)
- Custom cursor (desktop), side chapter navigation, reduced-motion support
- Fully responsive: Android, iOS, desktop. No horizontal scroll.

Run locally

Just open `index.html` in any browser. No server needed.

Deploy free on GitHub Pages

1. Create a new repository on GitHub (e.g. `anaya-xvii`).
2. Upload `index.html`, `favicon.svg`, and this `README.md`.
3. Go to Settings → Pages.
4. Under Source, choose Deploy from a branch, pick `main`, folder `/ (root)`, then Save.
5. Wait 1 minute. Your site goes live at:
   `https://<your-username>.github.io/anaya-xvii/`

Customise

- Letter text: search for `letter-inner` in `index.html`.
- Secret message: search for `id="secret"`.
- Colors: edit the CSS variables in `:root` at the top.
- Countdown date: edit the `targetDate()` function (currently October 28).
